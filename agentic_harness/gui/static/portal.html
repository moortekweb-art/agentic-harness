Local Network Portal

One page of links to the services on your local network. The list is loaded from an operator-supplied services.local.json next to this page — no hostnames are baked into the app.

    No services configured yet

    This portal renders link cards from services.local.json, a file you create on the machine that runs the harness. It is kept out of version control, so your real hostnames never end up in a repository.

    1. Copy the template that ships with the app: cp services.example.json services.local.json inside agentic_harness/gui/static/ of this installation (the harness serves it next to portal.html).
    2. Edit each entry’s label, url, and note to match your real hosts and ports.
    3. Reload this page.
