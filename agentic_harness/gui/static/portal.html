Local Network Portal

One page of links to the services on your local network. The list is read from a configuration file you own, and served only over the harness’s authenticated API — no hostnames are baked into the app, and none are readable without your access token.

    This portal renders link cards from a configuration file you create on the machine that runs the harness. It lives in your own config directory, outside the installed package, so your real hostnames are never part of the app, never packaged into a build, and never served to an unauthenticated visitor.

    1. Create the file at ~/.config/agentic-harness/services.json (or set AGENTIC_HARNESS_PORTAL_SERVICES to any path you prefer; $XDG_CONFIG_HOME is honoured when set).
    2. Use the shipped template as the starting shape: {"services": [{"label": "...", "url": "https://...", "note": "..."}]}
    3. Give each entry a label and an http(s) url (both required) and an optional note. URLs that embed a username, a password, or a credential-shaped query parameter are refused, so keep secrets out of the links.
    4. Restrict the file to yourself: chmod 600 ~/.config/agentic-harness/services.json
    5. Reload this page.
